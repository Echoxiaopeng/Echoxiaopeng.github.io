双臂印花机上料

主实验任务为工业印花机上料：夹起衣角→ 送入印花机→ 对齐布面以便印花。基于 pi05_base微调；在腕视易丢目标、遮挡频繁的场景下，引入 MEM（Memory）短时视觉记忆，使当前帧视觉 token 融合近几帧运动与遮挡信息，再交给 VLA 决策。

  • 任务与数据：4腕相机（左右臂上下腕，无头视）。
  • MEM 视觉记忆（核心改动）：每路相机 6 帧短时序。在SigLIP ViT 内对同空间 patch 做因果时序注意力（每隔 4 层一次，复用空间 Q/K/V，几乎不加新参）；约第 18 层 drop past，只保留当前帧 token 送给 LLM——token 量接近4 路单帧，却带短时运动 / 遮挡信息。
  • 权重加载：能对齐的 SigLIP权重继承预训练，MEM 布局差异与等新模块随机初始化后微调。

Stack: pi05 · MEM · SigLIP · 双臂 · 相对位姿控制 · JAX / Flax

单臂元器件分拣

面向电子元器件分拣场景，基于 LingBot-VA（WAM）完成从数据采集、策略微调到真机部署的闭环，并针对工业场景实时性要求优化推理链路。

  • 数据与微调：搭建示教采集流程，完成多品类零件轨迹采集、清洗与格式标准化；基于预训练权重开展任务微调，提升分拣成功率与跨布局泛化能力。
  • 异步推理：分析端到端延迟瓶颈（视觉编码、去噪步数、控制下发），引入异步推理手段，将推理时间从 900 ms 压缩到 300 ms。

Stack: LingBot-VA · WAM · 示教采集 · 策略微调 · 异步推理 · 真机部署

深度强化学习充电枪装配

针对电动汽车充电枪装配中传统强化学习样本效率低、策略震荡及硬件利用率不足的问题，提出融合 HER（事后经验回放）、DPU（策略延迟更新）与双线程并行训练的 SAC 算法框架，在 Coppeliasim + UR5 仿真环境中完成柔顺装配策略学习。

  • 状态与奖励：设计 17 维状态空间与分阶段塑形奖励函数，引导策略逐步完成对准与插入。
  • 算法：创新融合 HER、DPU 及双线程训练架构，相较基准 SAC 收敛时间缩短 10.2 小时，平均装配步数减少 17 步。
  • 结果：最大接触力低于 3 N，装配成功率达 99%，兼顾样本效率、策略稳定性与柔顺性。

Stack: SAC · HER · Gazebo · UR5 · Python · 深度强化学习

成果：相关论文已投稿期刊

MuJoCo 仿真遥操

基于 MuJoCo 搭建仿真环境，对接松灵 Pika 遥操作主手，实现仿真侧遥操闭环，用于示教采集与操作链路验证。

  • 仿真环境：在 MuJoCo 中搭建机械臂 / 场景模型，完成物理仿真与可视化渲染。
  • 遥操对接：接入 Pika 主手，完成主从映射与控制下发，在仿真中实时驱动末端运动。
  • 用途：支撑示教轨迹采集、遥操手感调试及真机部署前的链路验证。

Stack: MuJoCo · 松灵 Pika · 仿真遥操 · Python
